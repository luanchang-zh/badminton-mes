# 知识库问答页面设计方案

更新：2026-11-13。已按确认方案接入正式 Vue 页面 `/rag/chat`，沿用 MES 登录、导航与标签栏。独立原型及验收截图中的回答与文档为隔离示例；LightRAG 当前尚未部署。

## 设计依据与范围

采用现有 MES 的深蓝导航、蓝白控件、系统中文字体、56px 全局页头与标签栏。沿用现有人脸/登录工作确认的 MES 图标。不增加移动端专用布局，桌面覆盖 1920×920、1366×768。

主要依据是 `src/layouts/BasicLayout.vue`、`src/styles/index.css` 和现有 Element Plus 控件。常规页面方案由 direct-frontend-design → frontend-design 路径完成，无外部生成资源。

## 布局与视觉

```text
MES 主导航 | 全局页头、标签栏
           | 历史会话 | 消息阅读区 | 来源面板（展开时）
           |          | 固定输入区 |
```

- 主导航 220px，可折叠为 64px；会话列 236px，在较窄桌面为 218px。
- 对话区自适应，回答正文最大宽度约 820px；正文与来源分别滚动，输入区始终可见。
- 按用户批注删除重复的页面标题、说明和知识库标签，工作区直接承接标签栏；移除底部可见性、保存、回答依据与快捷键提示。快捷键行为保留，生成状态通过读屏区域和停止按钮体现。
- 会话列顶部为“最近对话”和新建图标，其下为搜索；会话行从约 66px 缩至 56px。每行的省略号菜单提供重命名和删除，鼠标悬停或键盘聚焦时可见，当前会话始终显示操作入口。
- 新建、会话操作与删除图标复用项目 `@element-plus/icons-vue` 的 Edit、MoreFilled、Delete 路径。重命名和删除使用原型内弹窗，支持保存、取消、Escape 和焦点返回。
- 鼠标点击问题输入框、输入文字或选择检索方式时，输入区边框保持原样，不显示额外轮廓或光晕；键盘 Tab 导航保留焦点指示。
- 来源面板宽 328px；宽桌面并列展示，较窄桌面作为右侧抽屉，支持遮罩关闭、Escape 和焦点返回。
- 基础色：导航 #001529，背景 #f0f2f5，文字 #303133，分隔线 #e4e7ed。沿用 MES 蓝色方向，文本和按钮使用满足对比度的深蓝 #286bb4，焦点保留 #409eff。
- 页标题 21px，段落正文 14px，辅助与元信息至少 12px，圆角 3～6px。平面排版为主，边界用于区分会话、对话和证据。

## 页面状态

| 状态 | 页面行为 |
| --- | --- |
| 新会话 | 简洁引导和领域问题示例，点击示例只填入输入框 |
| 已有回答 | 左侧用户会话，中间答案及引用编号，点击展开右侧原文 |
| 生成中 | 发送切换为停止，保留用户阅读位置；生成状态可被辅助技术读取 |
| 停止 | 保存现有内容，标记已停止，可重新生成 |
| 回答失败 | 保留问题，显示失败提示和重试入口 |
| 未开通 | 展示开通指引，输入禁用 |
| 无文档 | 引导管理员补充资料，输入禁用 |
| 无命中 | 提示补充设备型号、工序或关键字 |
| 服务未连接 | 历史对话可看，显示连接提示，保留输入区域 |

顶部“页面状态”选择器属于设计评审控件，正式页面由真实 API 状态驱动。

## 交互与 API 对应

- 点击“最近对话”旁的新建图标创建空会话；每条会话可单独重命名、删除。删除当前会话自动切换到下一条，删除最后一条时回到空对话，首次发送时创建会话记录；删除其他会话不终止当前生成。正式实现由会话 API 分页读取；原型搜索只作用于示例数据。
- Enter 发送，Shift+Enter 换行，中文输入法组合输入不触发发送；问题最多 2000 字符。
- 检索模式使用“标准检索、综合检索、实体关联、全局概览、关联与概览”等用户可理解的名称，分别映射 naive/mix/local/global/hybrid。
- 先查询 `/api/rag/profile`，再读取会话；发送调用 `/api/rag/query/stream` 并携带 conversationId/requestId。
- meta 关联消息，delta 追加正文，reference_details 更新来源，done 按消息 status 收尾，error 显示失败。
- 停止时先调用 cancel，再中止本地流；页面缓存停用、切换会话和退出登录均清理请求。重试调用消息 retry 接口并保留旧失败记录。
- 来源只显示文档名与原文片段，原文跳转/下载随后续文档管理能力接入。

## 原型与验证

- 入口：`index.html`；样式 `proposal.css`；交互 `proposal.js`。无需安装依赖或请求模型服务。
- 15 项浏览器交互检查通过，包括七类页面状态、引用展开、停止/重试、历史搜索和导航折叠；控制台无脚本错误。
- 最新侧栏调整增加 17 项定向交互检查，并复查生成过程中菜单可用、删除其他会话不中断生成、弹窗 Escape、鼠标无高亮与键盘 Tab 焦点。用户批注视口 1201×797 下会话高度 56px、输入区可见、页面无溢出。
- 1920×920 与 1366×768 无页面横向或纵向溢出，输入区可见；短桌面来源抽屉、遮罩和 Escape 检查通过。
- 已修正低对比度、辅助文字过小和短窗口高度问题。列容器 workspace 采用贴边分栏，文字均在各列内部留白；经截图确认后，仅对本 HTML 添加 cramped-padding 值例外。其余扫描项已清除。
- `preview-1920.png`、`preview-1366.png` 为当前本地截图。

## 正式 Vue 实现与验收

- 页面：`src/views/rag/RagChatView.vue`，复用 BasicLayout；交互状态集中在 `src/composables/useRagChat.ts`，会话、消息、输入和来源拆为组件。
- API：`src/api/rag.ts`；`src/utils/sse.ts` 处理事件边界和资源释放；退出及改密先取消生成。正式页面没有示例回复或状态切换器。
- 会话按用户从 API 读取全部分页后搜索；消息先读取最后一页，可加载更早内容。浏览器只保存所选会话 ID，消息正文仍从后端恢复。
- 模型输出通过 Vue 文本节点呈现段落、列表、代码、表格和引用；链接仅开放 HTTP/HTTPS。
- 53 项 Playwright 检查通过，覆盖会话操作、中文输入、来源抽屉及焦点返回、停止/重试、断线重发、快速切换、缓存重进、身份变更和 401；8 项 SSE 检查覆盖 UTF-8 跨块、CRLF、多行、半截事件、取消及大小限制。
- 1201×797、1366×768、1920×920 无页面溢出，输入区始终可见；鼠标无高亮、键盘 Tab 焦点符合确认方案。类型和生产构建、增量语法与设计扫描通过。
- 正式页面本地截图：`vue-preview-1920.png`、`vue-preview-1366.png`。测试入口为仓库 `tests/rag-chat.browser.js`、`tests/rag-sse.test.mjs`。Docker 前后端已更新；部署版聊天 51 项及人脸采集 13 组回归通过，真实 Nginx/MySQL 接口 24 项通过。LightRAG 真实检索联调待服务部署。
