开机前检查

开机前应依次检查电源与急停装置、传动机构、气路以及作业区域。急停按钮复位后，先进行空载试运行，确认设备无异响、无异常振动。

异常处理

发现传动带松动、气压异常或防护装置缺失时，应停止开机并报修。完成处理、确认安全后再恢复作业。
